# Student Information Management using Dictionary and Set

## Introduction

This is a simple Python program for managing student information using
Dictionary and Set data structures.

The program stores student names, roll numbers, and marks. It also performs
different operations such as adding, updating, deleting, searching and
finding marks. Set operations are also used to handle unique marks and
duplicate values.

## Features

The program performs the following operations:

1. Creates a dictionary containing student information.
2. Displays dictionary keys, values and key-value pairs.
3. Adds a new student.
4. Updates marks of an existing student.
5. Deletes a student.
6. Checks whether a student exists in the dictionary.
7. Finds maximum and minimum marks.
8. Creates a set of unique student marks.
9. Adds and removes elements from a set.
10. Performs union, intersection, difference and symmetric difference.
11. Checks subset and disjoint conditions.
12. Removes duplicate marks using a set.
13. Counts the frequency of each mark using a dictionary.
14. Displays the final student dictionary and unique marks.
